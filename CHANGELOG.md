# Changelog

All notable changes to SafeLens will be documented in this file.

The format follows Keep a Changelog, and this project aims to follow Semantic
Versioning after the first public release.

## [0.1.0] - 2026-09-14

### Added

- Initial SafeLens package structure with core interfaces for probes, monitors,
  attributors, model wrappers, pipeline configuration, and reports.
- YAML-driven pipeline runner and CLI entry point.
- Dummy method implementations for local tests and demos.
- HuggingFace, ModelScope, and Qwen3 Dense model loading scaffolding.
- TransformerLens-inspired hook, cache, and activation patching primitives.
- MkDocs documentation structure.
- GitHub Actions workflow for quality checks, documentation build, and Pages
  deployment.
- Open-source repository metadata, contribution guide, security policy,
  citation metadata, and GitHub issue and pull request templates.
- Local Explorer workspace with packaged React frontend, artifact API, job API,
  NLA/J-Lens/SAE/attribution/patching/intervention workflows, and Docker image.
- TransformerLens-compatible naming, architecture bridge adapters, and
  model-adapter registry inspection commands.
